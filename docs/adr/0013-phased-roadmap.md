# 0013. Phased roadmap

Status: Accepted

## Context
The full vision is large; each stage should produce a working pet.

## Decision
1. Phase 1: expressive pet (touch + face + motion).
2. Phase 2: offline voice + local LLM.
3. Phase 3: camera/NPU face detection, then a mobile EMO-style base.

## Consequences
- Phase 1 needs only the ESP32 side plus a minimal brain.
- Camera and mobile base hardware: TBD, decided at the start of Phase 3.
