# 0006. No ROS 2 on the robot

Status: Accepted

## Context
The 2GB RAM budget is dominated by the voice pipeline (ADR 0002, 0007). There is only one
link (UART) and one Linux process group to coordinate.

## Decision
Do not run ROS 2 on the robot. The brain is plain Python.

## Consequences
- Lower RAM and CPU overhead, simpler deploy.
- No ROS tooling (rosbag, rviz); logging and debugging are custom.
- Gazebo is not used either (ADR 0010).
