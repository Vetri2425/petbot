# PetBot protocol v1 shared test vectors (protocol/PROTOCOL.md).
# Run by brain/tests/test_vectors.py (Python) and firmware/test/ (C++ Unity, native).
#
# Format, one case per line:
#   VALID <line>  # => <expected encode(parse(line)) without the \n>
#   INVALID <line>  # <reason>
# <line> starts after the first space and ends at the first "  #" (two spaces, hash).
# Escapes in <line>: \\ \n \r \t \xHH. Leading/trailing spaces are written as \x20.
# A <line> without a trailing \n is parsed as if terminated by \n (the \n counts toward 128 bytes).
